# Employee Guide 3 — Leave Management

---

## Overview

If you are on leave (annual leave, sick leave, etc.), you should log a leave entry in the Timesheet module instead of project hours. Leave entries ensure your record is complete and prevent unnecessary reminder emails for missing timesheets.

**Navigation:** Sidebar → 🗒️ **Timesheet** → Click **"⛱️ Add Leave"** button

---

## 1. Why Log Leave?

| Without Leave Entry | With Leave Entry |
|--------------------|-----------------|
| System sees empty days | System knows you were on leave |
| You receive reminder emails | No reminder email sent |
| Hours appear missing | Days correctly accounted for |
| Reports show gaps | Reports show accurate headcount |

---

## 2. Types of Leave

| Leave Type | When to Use |
|------------|-------------|
| **Annual Leave** | Planned paid leave / vacation |
| **Sick Leave** | Illness or medical appointment |
| **Unpaid Leave** | Leave without pay |
| **Other** | Any leave not covered above |
| **Holiday** | Public holiday (usually added by admin) |

---

## 3. Adding a Leave Entry

### Step-by-Step

1. Go to the **Timesheet** module.
2. Click the **"⛱️ Add Leave"** button.
3. A dialog opens. Fill in:

| Field | Required | Description |
|-------|----------|-------------|
| Leave Type | ✅ Yes | Select from: Annual / Sick / Unpaid / Other / Holiday |
| Start Date | ✅ Yes | First day of your leave |
| End Date | ✅ Yes | Last day of your leave (must be on or after Start Date) |
| Reason | ✅ Yes | Brief explanation for the leave |

4. Click **Save**.

### Success Message
> ✅ "Leave entry added successfully."

---

## 4. Single-Day Leave

To add leave for just one day:
- Set **Start Date** and **End Date** to the **same date**.

---

## 5. Multi-Day Leave

To add leave for multiple days (e.g., a week's vacation):
1. Set **Start Date** to the first day of leave.
2. Set **End Date** to the last day of leave.
3. The system creates a leave record covering that entire range.

---

## 6. Editing a Leave Entry

You can edit leave entries within the **current week** only.

### How to Edit

1. Find the leave entry in the timesheet table (it will show as "Leave" under the Activity column).
2. Click the **Edit** (✏️) button.
3. Modify the fields.
4. Click **Save**.

> [!NOTE]
> Leave entries from previous weeks cannot be edited by employees. Contact your admin for corrections to past leave.

---

## 7. Deleting a Leave Entry

1. Find the leave entry in the table.
2. Click the **Delete** (🗑️) button.
3. Confirm deletion.

> [!CAUTION]
> Deleting a leave entry will make those days appear as missing in your timesheet record. Only delete if you added leave by mistake.

---

## 8. How Leave Affects the System

| Impact | Description |
|--------|-------------|
| Reminder Emails | Leave days are **excluded** from missing timesheet checks — no reminder sent |
| Reports | Leave entries appear in timesheet data but are **excluded from billable reports** |
| Holidays | Public holidays added by the admin automatically apply to your record |

---

## 9. Common Leave Errors

| Error | Cause | Fix |
|-------|-------|-----|
| "End date cannot be before start date" | End date earlier than Start date | Set End Date to same as or later than Start Date |
| "Reason is required" | Reason field left blank | Enter a brief reason for the leave |
| "Please select a leave type" | No leave type selected | Select one from the dropdown |

---

## 10. What About Public Holidays?

Public holidays are managed by your admin in **Settings → Holiday Management**. You do not need to add them manually — they are added system-wide and appear in your leave record automatically.

If a public holiday is missing from your record, contact your admin to add it.
