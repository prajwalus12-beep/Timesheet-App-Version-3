# 📚 Timesheet App — Help Documentation

Welcome to the official Help Documentation for the **FMP Timesheet Application**.

This documentation is separated by user role. Find your role below and follow the guides that apply to you.

You can also view this documentation interactively inside the application by navigating to **"❓ Help"** in the sidebar. The in-app documentation features a high-performance React interface with real-time search, interactive error lookup, and role switching.
